# 术语表 · 用一句话接住新概念

术语不是额外的背诵任务。遇到一个词，先理解它描述哪件事，再回到对应章节走一遍实际过程。同一个地址或端口出现在不同层时，含义可能不同。

## 数据与应用

| 术语       | 自然解释                                                                           | 对应章节                             |
| ---------- | ---------------------------------------------------------------------------------- | ------------------------------------ |
| 协议       | 通信双方共同遵守的规则，包括数据怎样表示、怎样交换以及遇到错误怎样处理。           | [数据包](/chapters/02-packets)       |
| 数据包     | 传输中的一块数据及其必要说明；一个请求可以拆成多个包，一个包也可能丢失。           | [数据包](/chapters/02-packets)       |
| 分层       | 把应用、传输、地址和实际搬运分开处理，让不同职责有清楚的交接位置。                 | [数据包](/chapters/02-packets)       |
| TCP        | 给应用提供可靠、有序的字节流，会处理确认、重传和拥塞；不保证网络永不失败。         | [协议与端口](/chapters/04-protocols) |
| UDP        | 以数据报方式交付数据，不由协议本身保证可靠和有序；上层可以另做可靠传输。           | [协议与端口](/chapters/04-protocols) |
| 端口       | 与 IP、协议配合识别通信端点的编号；服务监听端口与临时源端口用途不同。              | [协议与端口](/chapters/04-protocols) |
| 五元组     | 源 IP、源端口、目标 IP、目标端口和协议的组合，用于描述一条具体通信关系。           | [协议与端口](/chapters/04-protocols) |
| 监听       | 服务向操作系统登记接收新连接的地址、协议和端口；只监听回环地址通常不能被远端访问。 | [应用与 DNS](/chapters/17-apps-dns)  |
| 回环地址   | 代表本机内部的地址，例如 `127.0.0.1`；A 访问自己的回环地址不会连接到 B。           | [应用与 DNS](/chapters/17-apps-dns)  |
| HTTP       | 浏览器和网页服务常用的应用协议；得到 HTTP 错误答复和无法建立连接是不同阶段。       | [完整请求](/chapters/15-journey)     |
| DNS        | 把名称查询为地址等记录的系统；解析正确不会自动解决路由、监听或权限问题。           | [应用与 DNS](/chapters/17-apps-dns)  |
| 广播与组播 | 向一组接收者发送数据的方式；三层虚拟网络可达不代表局域网自动发现协议一定可用。     | [应用与 DNS](/chapters/17-apps-dns)  |

## 地址、路由与边界

| 术语     | 自然解释                                                                     | 对应章节                              |
| -------- | ---------------------------------------------------------------------------- | ------------------------------------- |
| IP 地址  | 网络层用于标识接口并选择目的地的地址；一台设备可以同时拥有多个接口与地址。   | [地址与网段](/chapters/03-addresses)  |
| 私有地址 | 留给内部网络使用的地址，很多不同家庭可重复使用；不能单靠它在公网定位设备。   | [地址与网段](/chapters/03-addresses)  |
| 公网地址 | 可以在公共网络中使用的地址；拥有它仍需正确监听与放行，才可能接受连接。       | [NAT](/chapters/06-nat)               |
| 网段     | 由一段共同的地址前缀表示的一组地址，例如 `192.168.20.0/24`。                 | [地址与网段](/chapters/03-addresses)  |
| CIDR     | 用地址加前缀长度表示网段的方法；`/24` 表示前 24 位是网络前缀，不是端口号。   | [地址与网段](/chapters/03-addresses)  |
| 路由表   | 指导系统或节点把目标地址交给哪个接口、网关或下一跳的规则集合。               | [路由](/chapters/05-routing)          |
| 网关     | 帮设备把数据送往其他网络的下一站；局域网默认网关未必知道虚拟网段在哪里。     | [路由](/chapters/05-routing)          |
| 默认路由 | 没有更具体匹配时采用的路由；改变它可能影响大量互联网流量。                   | [路由](/chapters/05-routing)          |
| 下一跳   | 当前节点准备把数据交给的下一站，不一定是业务的最终目标。                     | [拓扑](/chapters/14-topology)         |
| 回程     | 响应返回发起者的路径；去程能到达，不能自动证明回程正确。                     | [子网代理](/chapters/16-subnet-proxy) |
| NAT      | 在边界上修改地址或端口并维护对应关系的机制，常用于多个私网设备共享外部地址。 | [NAT](/chapters/06-nat)               |
| NAT 映射 | 内部端点与外部端点的对应关系；不同目的地是否共用映射影响打洞。               | [NAT](/chapters/06-nat)               |
| NAT 过滤 | 判断哪些外部来源可以进入已有映射的规则；应与映射规则分别理解。               | [打洞](/chapters/11-hole-punch)       |
| 防火墙   | 按规则允许或拒绝流量的机制；外层隧道端口与内层应用端口需要分别检查。         | [应用与 DNS](/chapters/17-apps-dns)   |
| ACL      | 访问控制列表，按来源、目标、协议、端口等条件表达谁可以访问什么。             | [应用与 DNS](/chapters/17-apps-dns)   |

## EasyTier 的结构与连接

| 术语             | 自然解释                                                                      | 对应章节                                |
| ---------------- | ----------------------------------------------------------------------------- | --------------------------------------- |
| 虚拟网络         | 建在现有网络之上的通信网络，使应用可以通过虚拟地址访问远方节点。              | [为什么需要 EasyTier](/chapters/01-why) |
| Underlay         | 实际承载数据的底层网络，包括 LAN、路由器与互联网链路。                        | [TUN](/chapters/07-tun)                 |
| Overlay          | 利用底层网络建立的上层网络；EasyTier 的虚拟节点和路由属于这一层。             | [TUN](/chapters/07-tun)                 |
| TUN              | 向程序提供三层 IP 包的虚拟网络接口，连接操作系统路由与用户态隧道程序。        | [TUN](/chapters/07-tun)                 |
| 隧道             | 把原来的数据放进另一层传输，再在目的端处理和取出的通信方式。                  | [完整请求](/chapters/15-journey)        |
| 封装             | 给原始数据加上外层说明，便于另一层网络搬运；它通常增加包大小。                | [完整请求](/chapters/15-journey)        |
| Peer             | 虚拟网络中的对等节点；节点身份不应仅靠一个显示主机名判断。                    | [成员关系](/chapters/09-membership)     |
| 网络名与网络密钥 | 本教程组网示例使用的成员配置，需按组网方式匹配；不是 HTTP 应用登录密码。      | [成员关系](/chapters/09-membership)     |
| 初始节点         | 启动时先连接的节点，帮助设备进入网络；它不必承担所有后续业务中转。            | [启动](/chapters/08-startup)            |
| STUN             | 帮助发现外部端点等 NAT 行为信息的协议；不负责替对方打开防火墙。               | [STUN](/chapters/10-stun)               |
| NAT 打洞         | 利用双方主动发包和映射信息尝试建立直接通信的过程，不保证所有网络都成功。      | [打洞](/chapters/11-hole-punch)         |
| P2P / 直连       | 两个目标节点之间直接建立通信关系；查看状态时必须先确认是对哪个节点。          | [排障](/chapters/19-diagnostics)        |
| 中转             | 由其他节点继续搬运发往目标的流量；可补充可达性，但有链路和资源成本。          | [中转](/chapters/13-relay)              |
| Mesh             | 节点形成可互相联系的网络结构，不等于每两个节点都有直接隧道。                  | [拓扑](/chapters/14-topology)           |
| 多跳             | 数据通过多个相邻节点连接到达目标；跳数不是中间节点数量。                      | [拓扑](/chapters/14-topology)           |
| 子网代理         | 一个节点把自己能访问的网段共享给虚拟网络，通过它访问未安装 EasyTier 的设备。  | [子网代理](/chapters/16-subnet-proxy)   |
| 系统转发         | 由操作系统处理跨接口转发；启用相应模式后，转发规则与回程需要明确设计。        | [子网代理](/chapters/16-subnet-proxy)   |
| 出口节点         | 为其他节点提供外部网络访问出口的节点，和访问某个远端 LAN 的子网代理用途不同。 | [子网代理](/chapters/16-subnet-proxy)   |
| 认证与加密       | 认证帮助确认身份，加密保护内容；两者不能替代应用层权限设计。                  | [安全](/chapters/12-security)           |

## 性能与观察

| 术语      | 自然解释                                                                | 对应章节                         |
| --------- | ----------------------------------------------------------------------- | -------------------------------- |
| RTT       | 一次数据往返所需的时间，包含两个方向和相关处理，不是单向延迟。          | [性能](/chapters/18-performance) |
| 带宽      | 链路能搬运数据的容量；它不等于当前应用已经达到的速度。                  | [性能](/chapters/18-performance) |
| 吞吐量    | 一段时间实际完成的数据传输量，受到协议开销、链路、丢包及系统处理影响。  | [性能](/chapters/18-performance) |
| 丢包      | 发出的包未按预期到达，需要结合路径和应用处理判断原因及影响。            | [性能](/chapters/18-performance) |
| MTU       | 接口或路径能承载的 IP 包大小上限；隧道封装后需留出额外空间。            | [性能](/chapters/18-performance) |
| KCP 代理  | EasyTier 用 KCP 搬运 TCP 流的能力，某些丢包环境可能受益，也有重传成本。 | [性能](/chapters/18-performance) |
| QUIC 代理 | EasyTier 用 QUIC 搬运 TCP 流的能力，不等于应用自动使用 HTTP/3。         | [性能](/chapters/18-performance) |
| 管理 RPC  | CLI 与本机 core 交换管理信息的接口；查询失败不必然表示远端隧道失败。    | [排障](/chapters/19-diagnostics) |

遇到表里没有解释的词，可以先看[学习路径](/)定位章节，再查看[来源](/sources)。
