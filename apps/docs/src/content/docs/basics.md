如果第一章里的“服务、端口、虚拟地址”还很陌生，从这里开始。你不用先背缩写。我们先让浏览器打开一个**由你自己的电脑提供的网页**，再看它怎样成功、怎样失败。后面的 EasyTier，只是在这条已经看得见的通信过程里增加了异地运输。

## 准备什么

准备一台电脑、Chrome 浏览器和 Python 3。Python 在这个实验里只是启动网页的小工具，不需要学 Python 编程。本机已安装时不再安装；第一节教你检查。没有 EasyTier 也能完成前五节；已有 GUI 时，第四节会帮助你读自己的地址。

[下载本机网页实验包（ZIP）](/downloads/network-basics-demo.zip)。解压后应该得到 `network-basics-demo` 文件夹，里面只有 `index.html`、`message.txt` 和 `README.txt`，不需要下载第三方依赖。文件也可在[公开源码仓库](https://github.com/sonofmagic/easytier-docs/tree/main/examples/network-basics-demo)中查看。

默认说明适用于 macOS。Windows、Linux 操作放在对应折叠里；请只跟自己系统的一套步骤。整个实验用专用文件夹，只监听本机，不改路由、Wi-Fi、防火墙或 EasyTier 配置。

## 做完以后

试着指着浏览器说：“我输入了目标地址和端口；正在运行的程序收到请求，把网页送回来。404 表示它回答了但没有那个文件；连接失败可能是程序已经停止。”能把这段话对应到你的真实窗口，就可以读[第一章](/chapters/01-why)了。仍不确定时回看第五节的三种现象，不用急着记 NAT 和打洞。

网站里的[三个交互实验](/labs)是后面的教学模型，和这个真实本机网页实验分别使用。网页实验也不能证明另一台电脑能访问你；这正是第一章的问题。

## 来源

实验采用 [Python 标准库 http.server](https://docs.python.org/3/library/http.server.html)，观察方法参考 [Chrome 网络面板文档](https://developer.chrome.com/docs/devtools/network/)。它是临时教学服务，不作为生产网站使用。
